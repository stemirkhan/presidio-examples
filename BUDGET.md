# Бюджет D09 и D11

D09 и D11 могут обращаться к платному API. Проверенный запуск — Linux / WSL,
Python 3.12. Общий журнал блокируется через `fcntl`, поэтому несколько запусков
на этом компьютере учитывают расходы совместно.

## Только локальная проверка

```sh
.venv-agent/bin/python d09_crewai.py --check-only
.venv-proxy/bin/python d11_litellm.py --check-only
```

Эти режимы намеренно проверяют отказ фильтра. Ключ и журнал бюджета не нужны;
шлюз без ключа запрещает обращение к провайдеру. Окружения и локальные модели
должны быть подготовлены по основному README. Новый журнал автоматически не создаётся.

## Подготовка платного запуска

Из каталога проекта один раз создайте журнал с выбранным пределом:

```sh
python3 init_budget.py --limit-usd 3
```

Допустим предел от 0 до 3 долларов; можно выбрать меньшую сумму. Ноль запрещает
любые платные обращения. Инициализация не вызывает API и не запрашивает ключ.
Повторный запуск команды откажется перезаписывать существующий журнал;
история резервов не сбрасывается. Утилита не увеличивает уже заданный предел.

Без локальной настройки используется `api-budget.json` в корне этого проекта.
Для общего журнала нескольких копий укажите абсолютный путь в приватном `local.json`:

```json
{"budget_file":"/absolute/path/to/shared/api-budget.json"}
```

Инициализатор и шлюз используют один и тот же путь. Относительный путь разрешается
от корня проекта. Для однократного создания файла по другому пути есть
`--budget-file /absolute/path/to/shared/api-budget.json`; для последующих запусков
этот же путь нужно указать в `local.json`. Журнал автора в пакет не входит.

После инициализации передайте свой `DEEPSEEK_API_KEY` через окружение или скрытый
запрос терминала и запустите D09 либо D11 по основному README. Ключ не записывается
в журнал. Локальные `local.json`, `api-budget.json`, файлы блокировки и журналы
запусков не следует добавлять в публичный репозиторий.

## Что именно ограничивает шлюз

Перед каждой отправкой шлюз резервирует оценочную верхнюю стоимость запроса.
Резерв учитывается совместно для D09/D11 и всех запусков с одним `budget_file`.
При нехватке остатка запрос останавливается до обращения к провайдеру.
После ответа дополнительно записывается оценка по `usage`; успешные и неудачные
обращения не освобождают ранее занятые резервы. Неопределённость после сетевого
сбоя не используется для повторного расходования той же суммы.

Это ограничитель по настроенным оценкам, а не гарантия счёта провайдера.
Константы `RATES` в `support/gateway.py` сохранены из учебного эксперимента:
они не объявляются актуальным тарифом. Перед платным запуском сверьте модель,
тарифы и доступные ограничения аккаунта у провайдера. Журнал не учитывает
вызовы из других программ, использующих тот же API-ключ.

Проверки учёта выполняются без API и моделей:

```sh
python3 -m unittest discover -s tests -p 'test_budget.py' -v
```
